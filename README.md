# Heart Disease Prediction and Status Monitoring System
### IBM SkillsBuild Internship Capstone Project

**Author:** Anumari Jyothi  
**Department:** Department of Statistics  
**Institution:** Pondicherry University  

## 📋 Project Overview
This project applies statistical analysis and Machine Learning frameworks (Logistic Regression) to predict the likelihood of heart disease in patients based on 14 critical clinical biometric markers. 

## 📁 Repository Structure
* **Heart_Disease_Prediction_Report.pdf** - Full formal academic project report.
* **Heart_Disease_Prediction_Code.pdf** - Documented Python model training pipeline.
* **Heart_Disease_Prediction_Requirements.pdf** - System hardware and software constraints.
* **Heart_Disease_Prediction_README.pdf** - Detailed setup and compilation guide.

## 🛠️ Environment & Tools
* Language: Python 3.x
* Libraries: Pandas, NumPy, Scikit-Learn
* Platform: Jupyter Notebook / VS Code
